# Scholar Chat

![Scholar Chat Banner](screenshots\Chat_App_Project.png)

A real-time mobile chat application built with Flutter and Firebase, allowing users to authenticate securely and exchange instant messages.

## Features
- **Authentication:** Secure Login and Registration using Firebase Auth.
- **Real-Time Messaging:** Instant 2-way chat powered by Cloud Firestore.
- **Clean UI:** Responsive interface with custom message bubbles.

## Tech Stack
- **Flutter & Dart**
- **Firebase Authentication & Cloud Firestore**
- **State Management:** Cubit / BLoC
